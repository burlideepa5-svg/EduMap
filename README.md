# EduMap
**An Interactive Career Guidance Web Application**

EduMap is a web-based career guidance and educational recommendation system developed as a BCA final year project. The project is designed to help students explore suitable career paths based on their interests, skills, personality traits, and academic background through interactive quizzes and personalized recommendations.

EduMap aims to simplify career exploration by providing structured guidance, career insights, and educational direction for students at different academic levels.

---

## Features

- Interactive career aptitude quizzes
- Personalized career recommendations
- Career cluster categorization
- Database-driven quiz response storage
- Downloadable result generation
- Sharable result feature
- Responsive and user-friendly interface
- Career exploration across multiple domains
- Dynamic result analysis based on user responses

## Database Setup

1. Install and start a local server environment such as:
   - WAMP
   - XAMPP

2. Start:
   - Apache
   - MySQL

3. Open phpMyAdmin

4. Create a database named:
   edumap

5. Import the file:
   edumap.sql

---

## How to Run the Project

1. Install a local server environment such as WAMP or XAMPP

2. Place the project folder inside the server directory:
   - WAMP: 'www'
   - XAMPP: 'htdocs'

3. Start Apache and MySQL

4. Open browser and run:
   http://localhost/EduMap/---
